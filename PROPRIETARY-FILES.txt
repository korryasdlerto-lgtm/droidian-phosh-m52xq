# Proprietary vendor blobs NOT included in this repository
#
# These files are copyrighted by Samsung Electronics, Qualcomm, ArcSoft and
# other vendors, and are extracted directly from the stock Samsung firmware
# for the Galaxy M52 5G (SM-M526B/SM-M526BR, codename m52xq). We do not have
# redistribution rights for them, so they are deliberately excluded from
# this public repo -- exactly the same way LineageOS/Halium official device
# trees exclude vendor blobs (their equivalent of an extract-files.sh +
# proprietary-files.txt), and the same convention used by the sibling
# Ubuntu Touch/Halium port of this device:
# https://github.com/korryasdlerto-lgtm/halium13-ubuntu-touch-m52xq
#
# If you own this exact device, you can obtain these files yourself from
# your own device's stock firmware/vendor partition (or by pulling them
# live off a running Halium/Droidian container with `adb pull`/`lxc-attach`
# + `cp`) and place them at these same relative paths under `v38-latest/`
# before building a flashable ZIP -- see README.md -> "Flashing".
#
# Also excluded for pure size reasons (unrelated to licensing, just not
# practical to keep in git): firmware/system.img, data/rootfs-chunks/ and
# data/userdata-overlay.tar.gz are multi-gigabyte and are represented in
# this repo only as symlinks pointing at a local, untracked
# `local-large-files/` folder -- see README.md -> "Repository layout".
#
# Everything else in this repo (all shell/python scripts, systemd units,
# config files, patched AOSP/LineageOS jars, and the libraries documented
# in README.md as our own rebuilds of public open-source projects, e.g.
# the patched libhybris EGL fix) is our own work and IS included.
